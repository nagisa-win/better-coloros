# 📋 features/ - 功能技术文档沉淀规范

本目录用于存放所有已实现及规划中的功能特性技术设计文档。

## 🎯 规范原则
任何开发者或 AI Agent 在接手新需求时：
1. **先写文档，后写代码**：在 `docs/features/{feature-name}.md` 中沉淀方案；
2. **拒绝重复造轮子**：检索已有的功能文档和 `common/` 共享类，确认是否已有类似实现；
3. **闭环交付**：功能完成后更新对应文档中的实际实现与测试结果。
